# Яндекс Алиса + Gemini + Serper Search (Vercel Serverless Webhook)

Production-готовый сервер для навыка Яндекс Алисы на базе **Google Gemini 2.0 Flash** с автоматическим поиском актуальной информации в интернете через **Serper API** и поддержкой сохранения контекста разговора без внешних баз данных (через `session_state` Диалогов).

---

## 🌟 Возможности

1. **Интеграция с Gemini 2.0**: быстрые голосовые ответы без задержек.
2. **Поиск через Serper**: при вопросах о свежих новостях, погоде или актуальных фактах Gemini автоматически делает поисковый запрос.
3. **Сохранение контекста разговора**: история Диалога хранится напрямую в `session_state` Яндекс Диалогов (без Redis, БД и лишних сервисов).
4. **Голосовая оптимизация**: ответы затачиваются под восприятие на слух (краткие, без markdown, звездочек, ссылок и списков, длина до 950 символов).
5. **Защита от таймаутов Яндекс Диалогов**: строго соблюдается лимит 3000 мс с автоматическим перехватом задержек.
6. **Готов к Vercel**: вывернута удобная обработка рерайтов (`/` и `/api/webhook` работают одинаково).

## 🚀 Переменные окружения (Vercel Environment Variables)

В панели **Vercel** (`Settings -> Environment Variables`) добавьте две переменные:

| Переменная | Описание | Обязательность |
| :--- | :--- | :--- |
| `GEMINI_API_KEY` | API-ключ Google Gemini (получить на [Google AI Studio](https://aistudio.google.com/)) | **Обязательно** |
| `SERPER_API_KEY` | API-ключ Serper Google Search (получить на [serper.dev](https://serper.dev/)) | *Опционально* (для поиска) |

## 📡 URL Вебхука для Яндекс Диалогов

После деплоя в Vercel ваш вебхук будет доступен по следующим адресам:

- `https://<имя-вашего-проекта>.vercel.app`
- `https://<имя-вашего-проекта>.vercel.app/api/webhook`

Оба адреса работают идентично!

## 🛠️ Настройка Навыка в Яндекс Диалогах

1. Перейдите в [Консоль Яндекс Диалогов](https://dialogs.yandex.ru/developer/).
2. Нажмите **Создать диалог** -> Выберите **Навык в Алисе**.
3. Заполните основные настройки:
   - **Название**: Назовите ваш навык (например, *Умный Помощник*).
   - **Имя для активации**: Фраза для запуска (например, *Запусти умного помощника*).
   - **Backend / Webhook URL**: укажите ваш Vercel URL (например, `https://alisa-gemini-skill.vercel.app/api/webhook`).
4. Нажмите **Сохранить**.
5. Перейдите во вкладку **Тестирование** и проверьте диалог:
   - При открытии Алиса поздоровается.
   - Задайте любой вопрос (например, *"Какая погода в Москве?"* или *"Кто победил на чемпионате мира?"*).
6. Когда всё работает, нажмите **Опубликовать** (или используйте навык в приватном режиме со своего аккаунта Яндекса).
